# ARXEYA Android Releases

Public distribution artifacts for ARXEYA Android owner testing.

Current debug test version: `0.1.4-updater-diagnostics-auth-status` (`versionCode=5`).

Only safe release artifacts belong here: APK files, `app_latest.json`, `content_manifest.json`, install notes, changelogs, and checksums. Source code, secrets, keystores, `local.properties`, and private configs must not be published here.

Android may show Play Protect for sideloaded/debug APKs from GitHub. This is expected Android system behavior.
